Nexus Lamp

The 3D printed shopware Nexus logo, lit from the inside, that blinks when a pull request lands. Everything below happens in this browser tab — no software to install.

This browser cannot talk to USB devices. Please use Chrome or Edge on a desktop — Safari and Firefox do not support Web Serial. Web Serial needs a secure connection (https).

What to do

  1. Plug the lamp into your computer with a USB-C data cable — charge-only cables will not show up.
  2. Hit Connect above and pick the serial port. On macOS it is called cu.usbserial-0001, on Windows something like COM3.
  3. Choose Install Nexus Lampe and wait about a minute.
  4. When it asks for WiFi, enter your own network. The lamp remembers it across reboots and updates. It needs a 2.4 GHz network — the chip has no 5 GHz radio.

No cable handy?

A lamp that has not been set up yet opens its own hotspot called Nexus Lampe Setup. Join it with a phone or laptop and a setup page appears by itself; if it does not, browse to http://192.168.4.1. Same result, no cable required.

Home Assistant

Optional. If you run Home Assistant, it discovers the lamp on its own once it is on your WiFi — you will be asked for an encryption key, which comes with the lamp. Without Home Assistant the lamp still works: it has its own web page at http://nexus-lampe-<id>.local.
